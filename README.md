# mdew（インライン編集に対応したシンプルな Markdown エディタ）

mdew は、Markdown ファイルをプレビューと同じ見た目のまま直接編集できる、Windows デスクトップ用の
Markdown エディタです。編集用とプレビュー用の画面が分かれていないので、書式が実際にどう見えるかを
確認しながら、そのまま書き進められます。mde と同じ使い方で、画面を HTML（Microsoft Edge WebView2）で
作り直したものです。

このドキュメントは、mdew を初めて使う方向けのガイドです。

## 起動

インストーラー（`mdew.msi`）でインストールすると、スタートメニューに「mdew」が登録されます。インストールの途中で
選ぶと、エクスプローラーの右クリックメニューに「mdew で開く」も追加されます（.md ファイルを選んだ時と、フォルダの
何もない場所を右クリックした時）。インストールせずに、ビルドした `mdew.exe` を直接実行しても起動します。

mdew の実行には、次の2つが必要です（どちらも同梱していません）。

- **.NET 10 Desktop Runtime**：入っていない場合は、起動しようとした時に「.NET をインストールしてください」という
  案内が表示されます（.NET 自体の標準の機能です）。案内に従ってインストールしてから、もう一度起動してください。
- **Microsoft Edge WebView2 ランタイム**：Windows 11 には最初から入っています。

起動時の引数に Markdown ファイルのパスを渡すと、そのファイルを開いた状態で起動します。フォルダのパスを渡すと、
そのフォルダをフォルダビューに開いて、直下の最初のファイルを開きます。デスクトップのショートカットのリンク先
（プロパティの「リンク先」欄）にパスを書き足しておけば、そのショートカットから特定のファイル・フォルダを
すぐに開けます。

2回目以降の起動では、ウィンドウの位置・大きさ（最大化していたか）、アウトライン・ステータスバーを表示するか、
アウトライン・フォルダビューの幅、段落中の改行の表示を、前回終了した時と同じにします。

## 画面の見方

- **メニューバー**（上端）：「ファイル」「表示」のメニュー、「検索と置換」のボタン、「ヘルプ」のメニュー
  （「Readmeを開く」でこの文書を新しいウィンドウで開きます。F1 キーでも開けます）。
- **フォルダビュー**（左端）：「ファイル」→「フォルダを開く...」で開いたフォルダの中の Markdown ファイルの一覧。
  フォルダを開いた時だけ表示されます。
- **アウトライン**：今開いているファイルの見出しの一覧。クリックすると、その見出しの位置へ移動します。
- **編集領域**（右側の大部分）：文章を書く場所。ここに表示されている内容がそのまま保存されます。
- **ステータスバー**（下端）：左端の「フォルダを隠す／表示」「アウトラインを隠す／表示」のボタンで、フォルダビュー・
  アウトラインの表示・非表示をワンクリックで切り替えられます（「フォルダ」のボタンは、フォルダを開いている時だけ
  表示されます）。その右の「ソースを表示」（ソースモードでは「Markdownを表示」）のボタンで、ソースモードと
  通常の表示を切り替えられます。リンクの上にマウスを乗せた時は、リンク先を表示します。

ペインの境界をドラッグすると、フォルダビュー・アウトラインの幅を変えられます（境界をダブルクリックすると
元の幅に戻ります）。メニュー「表示」で、フォルダビュー・アウトライン・ステータスバーの表示・非表示を
切り替えられます（表示している時は ✓ が付きます）。

文書の表示倍率は、メニュー「表示」の「拡大」「縮小」「100%に戻す」、または **Ctrl+マウスホイール**
（編集領域の上で）で変えられます（48%・57%・69%・83%・100%・120%・144%・172%・207%・248% から選びます。今の倍率はメニュー「表示」に表示されます）。文字・画像を
まとめて拡大・縮小します。メニュー・アウトライン等の大きさは変わりません。倍率は次回起動時も同じになります。

本文の幅は、メニュー「表示」の「本文の幅」で切り替えられます。「読みやすい幅にする（最大 884px）」（既定）では、
ウィンドウを広げても本文は最大 884px の幅で中央に表示します。「編集ペインの幅に合わせる」では、編集領域の幅いっぱいに
表示します（列の多い表を広く表示したい時等）。切り替えは次回起動時も同じになります。

文書の見た目は、メニュー「表示」の「表示スタイル」で切り替えられます。「GitHubスタイル」（既定）と、Visual Studio Code
の Markdown のプレビューに似せた「VSCodeスタイル」（Segoe UI の 14px、見出しの下の淡い線、下線なしのリンク、赤い字の
コード、縦の線の無い表等）があります。ソースモードの文字・PDF への書き出しも、選んだ見た目になります。切り替えは
次回起動時も同じになります。

文字の色は、メニュー「表示」の「文字の色」で切り替えられます。「くっきりした色」（既定。ほぼ黒）と、少し薄い灰色で
線が細く見える「目にやさしい色」があります。本文・ソースモード・メニュー・ステータスバーの文字の色がまとめて変わります。
切り替えは次回起動時も同じになります。

開いているファイルの名前は、タイトルバーに表示されます。保存していない変更がある時は、名前の先頭に「*」が
付きます。

## 基本操作

| 操作 | 方法 |
|---|---|
| 新規作成（新しいウィンドウ） | メニュー「ファイル」→「新規」、または `Ctrl+N` |
| ファイルを開く | メニュー「ファイル」→「開く」、または `Ctrl+O` |
| 最近使ったファイルを開く | メニュー「ファイル」→「最近使ったファイル」から選ぶ |
| 最近使ったフォルダを開く | メニュー「ファイル」→「最近使ったフォルダ」から選ぶ |
| フォルダを開く | メニュー「ファイル」→「フォルダを開く...」 |
| 上書き保存 | メニュー「ファイル」→「保存」、または `Ctrl+S` |
| 名前を付けて保存 | メニュー「ファイル」→「名前を付けて保存」、または `Ctrl+Shift+S` |
| すべて保存 | メニュー「ファイル」→「すべて保存」（フォルダを開いている時に、変更したファイルをまとめて保存する） |
| PDF に書き出す | メニュー「ファイル」→「PDFに書き出し…」、または `Ctrl+P` |
| ウィンドウを閉じる | メニュー「ファイル」→「閉じる」、または `Ctrl+W` |
| 元に戻す・やり直し | `Ctrl+Z`・`Ctrl+Y` |

「新規」は、新しいウィンドウを開きます（今のウィンドウの内容はそのまま残ります）。

メニューの「開く」「最近使ったファイル」「フォルダを開く...」「最近使ったフォルダ」（`Ctrl+O` も）は、今のウィンドウで
フォルダやファイルを開いている時や、何か書いてある時は、新しいウィンドウで開きます（今のウィンドウの内容は
そのまま残ります）。何も書いていない新しいウィンドウでは、そのウィンドウで開きます。今のウィンドウで開いている
ファイル・フォルダそのものを選んだ時は、新しいウィンドウは開きません。

保存していない変更がある状態でウィンドウを閉じると、「閉じる前に保存しますか？」の確認が表示されます。
「はい」で保存してから閉じ、「いいえ」で保存せずに閉じ、「キャンセル」で閉じるのをやめます。

メニュー「ファイル」→「最近使ったファイル」には、最近開いた・保存したファイルが、新しい順に 10 個まで
フルパスで表示されます。クリックするとそのファイルを開きます。ファイルが移動・削除されている場合は、その旨が
表示され、一覧からも取り除かれます。「履歴をクリア」で一覧を空にできます。一覧は、ほかのウィンドウとも
共通です。

メニュー「ファイル」→「最近使ったフォルダ」には、「フォルダを開く...」で開いたフォルダが、同じように新しい順に
10 個まで表示されます。クリックすると、そのフォルダをフォルダビューに開きます。

### 編集していない部分はそのまま保存される

mdew は、見出し・段落・箇条書き・表・コードブロックといったまとまり（ブロック）ごとに、実際に編集した
ブロックだけを保存時に書き直します。触っていない部分は、読み込んだ時の書き方（余白や改行の位置など）が
そのまま保たれます。そのため、開いて保存しただけで差分だらけになる、といったことが起きにくくなっています。

## 書式の書き方

編集領域に、見た目そのままで書式が反映されます。

| 書きたいもの | 入力方法 |
|---|---|
| 見出し | 行頭で `#` に続けてスペース（`#`〜`######` で見出し1〜6） |
| 引用 | 行頭で `>` に続けてスペース |
| 太字 | `**太字にしたい文字**`、または文字を選んで `Ctrl+B` |
| 斜体 | `*斜体にしたい文字*`、または文字を選んで `Ctrl+I` |
| 取り消し線 | `~~取り消し線にしたい文字~~`、または文字を選んで `Alt+Shift+5` |
| 下線 | 文字を選んで `Ctrl+U`（保存すると `<u>…</u>` になります） |
| ハイライト | `==ハイライトしたい文字==` |
| インラインコード | `` `コードにしたい文字` ``、または文字を選んで `` Ctrl+Shift+` ``（日本語キーボードでは `Ctrl+Shift+@` の位置） |
| 箇条書き | 行頭で `-`（`*`・`+` でも可）に続けてスペース |
| 番号付きリスト | 行頭で `1.` のように数字＋ピリオドに続けてスペース |
| チェックボックス | 箇条書きの項目の先頭、または表のセル（見出しの行以外）の先頭で `[ ]`（未チェック）または `[x]`（チェック済み）に続けてスペース（表のセルでは、スペースは無くてもよい） |
| 水平線 | `---` と入力して Enter |
| コードブロック | 行頭で `` ``` ``（言語名を続けてもよい：`` ```csharp ``）と入力して Enter |
| 表 | `|見出し1|見出し2|` のように入力して Enter |
| リンク | `[表示する文字](URL)`、または `<https://...>` |
| メールアドレスのリンク | `<name@example.com>` |

これらの記号は、閉じ側の記号を打ち終えた時点で、見た目の書式に変換されます。保存する時には、元の Markdown の
記法に戻ります。

文字を選んで右クリックすると、太字・斜体・下線・取り消し線・インラインコード・ハイライトを、メニューから
設定・解除できます（設定されている書式には ✓ が付きます）。

文字を選んで右クリック→「リンクにする…」で、リンク先の URL を入力して、選んだ文字をリンクにできます。

右クリック→「ページトップに戻る」で、文書の先頭を表示します（カーソルも先頭に移ります）。ソースモードでも使えます。

段落・見出しの上で右クリック→「見出し」から、見出しのレベル（見出し1〜6）を変えたり、本文に戻したりできます
（今のレベルには ✓ が付きます）。

### 箇条書き・リストの操作

- 項目の途中で **Enter**：次の項目を追加
- 項目の途中で **Shift+Enter**：項目の中で改行（新しい項目にはなりません）
- **Tab**：字下げ（入れ子のリストにする）
- **Shift+Tab**：字下げを戻す
- 空の項目で **Enter**：リストから抜ける（入れ子の項目なら、1段上に戻ります）
  - リストの途中で1段上に戻ると、後ろの項目はその項目の入れ子になります（Markdown の決まり）。戻った項目に文字を
    書けば、その下に後ろの項目が並びます。空のままにしたい時は、その空の行で **BackSpace** を押すと、元の形に戻ります
- 入れ子のある項目の先頭で **BackSpace**：項目の文字を1つ上の行につなげ、入れ子の項目も前の項目の下へ移します
  （Wordと同じ）

チェックボックスはクリックで、チェック・未チェックを切り替えられます。チェックボックスの項目の先頭で
BackSpace を押すと、チェックボックスを外して通常の項目に戻ります。

表のセル（見出しの行以外）の先頭にも、チェックボックスを置けます。セルの先頭で `[ ]` または `[x]` と打つと
（後ろのスペースは無くてもかまいません）、チェックボックスになります（ファイルには、セルの先頭の `[ ]`・`[x]` として
保存されます。GitHub 等の他のアプリでは、`[ ]` の文字のまま表示されます）。セルの先頭で BackSpace を押すと、
チェックボックスを外します。

### 見出し・引用の操作

見出しの先頭で BackSpace を押すと、通常の段落に戻ります。引用の先頭で BackSpace を押すと、引用を解除します。
引用の最後の空の行で Enter を押すと、引用から抜けます。

### コードブロックの操作

コードブロックの中では、Enter は改行として働きます。**Tab** でタブ文字を入れられます。コードブロックから
抜けるには、上下の行をクリックしてください。

### 貼り付け

ほかのアプリからコピーした文字は、Markdown として読み、見出し・リスト・表・太字などの書式にして貼り付けます。
Claude などのチャット・Web ページ・Word などからコピーした書式付きの内容は、Markdown の書き方に直して貼り付けます
（箇条書き・番号付きリスト（入れ子も）・見出し・太字・斜体・取り消し線・リンク・インラインコード・
コードブロック・引用・表・画像。文字の色や大きさなどの飾りは捨てます）。
書式にしたくない時は、**Ctrl+Shift+V**（または右クリック→「書式なしで貼り付け」）で、文字のまま貼り付けます。
コピーした画像は、画像として貼り付けます（[画像](#画像) 参照）。

### 段落中の改行

ソースの1行の終わり（空行を挟まない、単純な改行）をどう表示するかは、メニュー「表示」→「段落中の改行」で
選べます。既定は「空行が入るまで改行しない」で、空行を挟まない改行は空白として扱われ、段落は画面の幅で
折り返して表示されます（VSCode の Markdown プレビューと同じです）。「ソースの通りに改行する」に切り替えると、
ソースの改行がそのまま見た目の改行になります。どちらの表示でも、保存する内容は変わりません。

段落の途中で **Shift+Enter** を押すと、その場で改行します（保存すると、ソースの改行になります）。

## 表（テーブル）

`|見出し1|見出し2|` のように入力して Enter を押すと、表になります（見出しの行と、空の行が1行作られます）。
右クリック→「表を挿入…」で、行数（見出しの行を含む）と列数を指定して、空の表を作ることもできます（右クリックした
段落の後ろに作られます。空の段落の上なら、その段落が表になります）。

- **Tab**・**Shift+Tab**：次・前のセルへ移動します。最後のセルで Tab を押すと、行を追加します。
- **Ctrl+Enter**：下に行を挿入します。
- 表のセルの上で右クリックすると、行・列の挿入・削除、表をコピー、表を削除ができます。

## Excel・他のアプリとの連携

- **Excel から貼り付け**：Excel で選んだ範囲をコピーして mdew に貼り付けると、表になります（1つ目の行が
  見出しの行になります）。範囲の中に画像があれば、画像も一緒に貼り付けます。タブ区切りの文字の貼り付けも、
  表にします。
- **Excel へ貼り付け**：右クリック→「Excel用にコピー」で、選んだ見出し・段落・箇条書きの項目などを、Excel で
  1行1セルに分かれて、太字などの見た目も保ったまま貼り付けられる形でコピーします。表の中では、選んだセルの範囲を
  コピーします。右クリック→「表をコピー」（表のセルの上）では、表全体を罫線付きでコピーします。
  画像も一緒に貼り付けられます（画像は一時的なファイルとして書き出すので、コピーしたら早めに貼り付けて
  ください）。Excel では、画像が下の行の文字に重なって表示されることがあります。
- **通常のコピー**（`Ctrl+C`）：Word などのほかのアプリには、見出し・表などの書式付きで貼り付けられます。
  mdew どうし（別のウィンドウ）では、見出し・リスト・表などの書式のまま貼り付けられます。

## 画像

`![説明](images/a.png)` の形のほか、`<img src="images/a.png" width="200">` の形（HTML のタグ）で書いた画像も
表示します。相対パスの画像は、開いているファイルのフォルダを基準にして表示します。`C:\...` のような絶対パスの
画像も表示できます。

クリップボードにコピーした画像（スクリーンショット等）は、`Ctrl+V` で貼り付けられます。貼り付けた画像は、
**保存するまでの間は一時フォルダに置かれ**、保存すると、編集中のファイルと同じフォルダの
`<ファイル名>.images` フォルダへ移ります（同じ名前のファイルがある場合は、連番を付けて重ならないようにします）。

画像をダブルクリックするか、右クリック→「画像を開く」を選ぶと、Windows で関連付けられた既定のアプリ
（フォト等）でその画像を開きます。

## リンク

リンクは青字＋下線で表示され、**クリック**で開きます（Ctrl は不要です）。リンクの文字を編集する時は、矢印キーで
カーソルを移動してください。リンクの上にマウスを乗せると、ステータスバーにリンク先が表示されます。

- `http://`・`https://`・`mailto:` のリンク：既定のブラウザ・メールソフトで開きます。
- 文中にそのまま書いたメールアドレス（`name@example.com`）も、mailto のリンクとして表示されます（GitHub と同じ。
  ファイルには書いたまま、`< >` を付けずに保存されます）。入力した時は、後ろに空白・句読点等を打つか、Enter を
  押した時にリンクになります。
- `#見出し` のリンク：文書の中のその見出しへ移動します。
- 相対パスの Markdown ファイル（`other.md` 等）へのリンク：このウィンドウでそのファイルを開きます。

## フォルダビュー

メニュー「ファイル」→「フォルダを開く...」でフォルダを選ぶと、左端のフォルダビューに、そのフォルダの中の
サブフォルダと Markdown ファイル（`.md`・`.markdown`）が一覧表示されます。ファイルをクリックすると、そのファイルを
開きます。フォルダをクリックすると、開く・閉じるができます。名前が「.」で始まるフォルダは表示しません。

フォルダを開いている間は、保存せずに別のファイルへ切り替えても、変更は消えずに残ります。保存していない変更が
あるファイルは、名前の先頭に「* 」が付きます。メニュー「ファイル」→「すべて保存」で、まとめて保存できます。

フォルダビューの上の「…」ボタンから、別のフォルダを開き直せます（メニューの「フォルダを開く...」と違い、
このウィンドウのフォルダを切り替えます）。

## アウトライン

アウトラインには、今開いているファイルの見出しが、階層付きで一覧表示されます。見出しをクリックすると、編集領域の
その位置まで移動します。長い文書で目的の場所をすぐに見つけたい時に便利です。

下の階層の見出しがある見出しには「▾」が付き、クリックすると、その下の見出しを折りたためます（「▸」をクリックすると
広がります。フォルダビューと同じです）。折りたたんだ状態は、文章を編集しても、ソースモードに切り替えても保たれます。

## 検索と置換

メニューバーの「検索と置換」（または `Ctrl+F`）で、検索と置換のウィンドウを開きます。ウィンドウは、
メインのウィンドウの外へも動かせます。文字列を範囲選択してから開くと、その文字列が検索する文字列に入ります
（複数行にまたがる選択の時は入りません）。

- **対象範囲**：「現在のファイル」か「フォルダ全体（サブフォルダ含む）」を選べます（フォルダ全体は、
  フォルダを開いている時だけ選べます）。
- **大文字・小文字を区別する** / **正規表現を使用する**：それぞれチェックボックスで切り替えます
  （正規表現の置換後の文字列では、`$1` などが使えます）。
- **前を検索 / 次を検索**：見つかった箇所を1つずつ移動します。今の箇所はオレンジ、ほかの見つかった箇所は黄色で
  表示します。
- **すべて検索**（Enter）：見つかった箇所をまとめて一覧表示します。一覧をダブルクリックすると、その箇所へ
  移動します（フォルダ全体の場合は、そのファイルを開きます）。
- 「置換後の文字列」を開くと、**1件ずつ置換…**（「置換」「スキップ」「残りをすべて置換」を選びながら置換する）と
  **すべて置換**が使えます。

フォルダ全体の置換は、**保存するまで実際のファイルには書き出しません**。置換したファイルには、フォルダビューで
「* 」が付くので、メニュー「ファイル」→「すべて保存」でまとめて保存してください。

検索する文字列などの条件は、ウィンドウを閉じても、次に開いた時まで残ります（mdew を終了すると消えます）。
Esc キーでウィンドウを閉じます。

## ソースモード

メニュー「表示」→「ソースモード」で、Markdown のソースをそのまま編集するモードに切り替えられます。書式を
気にせず、文字として一括で編集したい時に使えます。もう一度選ぶと、元の表示に戻ります。右クリック→
「ソースモードに切り替え」（ソースモードでは「Markdownモードに切り替え」）や、ステータスバーの「ソースを表示」
（ソースモードでは「Markdownを表示」）でも切り替えられます。

切り替えた時は、切り替える前に見ていた段落などが、同じように一番上に見える位置を表示します。ソースモードでも、
保存・検索と置換・PDF への書き出しが使えます。ソースモードは終了時には覚えません（次回は通常の表示で
起動します）。

## PDF への書き出し

メニュー「ファイル」→「PDFに書き出し…」（`Ctrl+P`）で、今の内容を PDF に書き出せます。保存先を選ぶと、
A4 縦の PDF を作って開きます。追加のソフトウェアやインターネット接続は不要です。

- 文書の中の `#見出し` のリンクは、PDF の中でもクリックするとその見出しへ移動します。
- ページの余白は、メニュー「ファイル」→「PDFの余白を設定…」で、上下左右をそれぞれ指定できます
  （既定は上下 64px、左右 80px）。

## 困ったときは

- 動作がおかしいと感じた時は、一度ファイルを保存してから、ウィンドウを閉じて開き直してみてください。
- ウィンドウの位置や、最近使ったファイル・PDF の余白などの設定は、`%LocalAppData%\mdew\settings.json` に
  保存しています。このファイルを削除すると、初期の状態に戻ります。
- エラーが起きた時の記録は、`%LocalAppData%\mdew\error.log` に残ります。

開発者向けの情報（ファイルの構成・作りなど）は、`doc\DESIGN.md` を参照してください。
