# mdew

mde の画面を HTML で作り直したアプリケーションです。

## フォルダ構成

- `mdew.sln` / `mdew.csproj` / `Program.cs` / `AppSettings.cs`：WebView2 を載せる入れ物（WPF）。
  ファイルを開く・保存する、画像の保存など、OS とのやり取りを担当します（ari 版と同じもの）。
- `dialog\AboutWindow.xaml`：バージョン情報のウィンドウ（mde から移植）
- `ThirdPartyNotices.txt`：サードパーティ（WebView2 SDK）のライセンス表示。実行フォルダへコピーされます。
  NuGet のパッケージを追加・更新した時は、この中のバージョン・ライセンス文も直してください
- `web\`：画面側。ビルドは不要で、ここのファイルがそのまま実行フォルダへコピーされます。
  - `index.html` / `app.css`：画面の構成と見た目
  - `js\main.js`：画面全体の動き、ホスト（C#）とのやり取り
  - `js\editor.js`：編集部分（入力時の書式変換、元に戻す、編集していない部分を元のまま保存する仕組み）
  - `js\markdown.js`：Markdown の読み込み・書き出し

## ビルド

Visual Studio で `mdew.sln` を開いてビルドするだけです（Node.js は不要です）。

## 今できること（成立確認の範囲）

- 見出し・段落・箇条書き・番号付きリスト（入れ子）・チェックボックス・引用・コードブロック・水平線・表・画像・リンクの表示と編集
- 入力時の書式変換：行頭の `# ` `- ` `1. ` `> ` `[ ] `、`**太字**` `*斜体*` `~~取り消し線~~` `==ハイライト==` `` `コード` ``、
  「```」＋Enter でコードブロック、「---」＋Enter で水平線、「|見出し|見出し|」＋Enter で表
- リストの Tab / Shift+Tab、表のセル間の Tab 移動（最後のセルで Tab を押すと行を追加）
- 元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）
- 文字の書式：太字（Ctrl+B）・斜体（Ctrl+I）・下線（Ctrl+U）・取り消し線（Alt+Shift+5）・
  インラインコード（Ctrl+Shift+`）・ハイライト。右クリックのメニューからも使えます（表のセルの上では表の操作も）
- 「表示」のメニュー（Alt+V）：アウトラインを表示・ステータスバーを表示（表示中は ✓）、
  段落中の改行（ソースの通りに改行する／空行が入るまで改行しない。mde と同じ。既定は「空行が入るまで改行しない」）。
  次回起動時も同じ表示にします。
  「空行が入るまで改行しない」は表示だけの切り替えで、保存する内容は変わりません（改行のすぐ隣で文字を入力すると、
  その改行が空白に変わることがあります）
- 「ファイル」のメニュー（Alt+F）：新規（Ctrl+N）・開く（Ctrl+O）・保存（Ctrl+S）・名前を付けて保存（Ctrl+Shift+S）。
  新規は新しいウィンドウを開きます
- 開いているファイルの名前は、タイトルバーに表示します
- ステータスバーの「停止」「入力遅延」の回数（IME フリーズの検証用）は、Debug ビルドの時だけ表示します
- 文字の貼り付けは、Markdown として読んで書式（見出し・リスト・表・太字等）にします。
  書式にしたくない時は「書式なしで貼り付け」（Ctrl+Shift+V・右クリックのメニュー）
- 「バージョン情報」ボタンで、アプリ名・バージョン・著作権を表示します（mde の AboutWindow と同じ画面）。
  「サードパーティのライセンス」から ThirdPartyNotices.txt を開けます
- F12 で開発者ツール（画面側の調査・デバッグ用）を開きます
- リンクはクリックで開きます（`#見出し` は文書内の見出しへ移動、http(s)・mailto は既定のアプリ、相対パスの .md はこのウィンドウ）。
  リンクの文字を編集する時は、矢印キーでカーソルを移動します
- 編集していない部分を元のまま保存、クリップボードの画像の貼り付け

## フォント・文字の大きさの変更

`web\app.css` の先頭の `:root { … }` にまとめてあります（`--doc-font`・`--doc-font-size` 等）。
書き換えてビルドし直すと反映されます。
