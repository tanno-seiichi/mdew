## mde にできて mdew でまだできないこと

mde の README（`C:\src\mde_refactor\refactor\README.md`）と比べたもの。

### ファイル・ウィンドウ

- [ ] 同じウィンドウで新規作成（mde は Ctrl+N。mdew の Ctrl+N は新しいウィンドウ＝mde の Shift+Ctrl+N）
- [ ] Ctrl+← / Ctrl+→ で、前・後に開いていたファイルへ移動
- [ ] 閉じる・切り替える時の確認で「保存する」を選べるようにする（mdew は「破棄して閉じますか」のはい・いいえだけ）
- [ ] メニューの項目を矢印キーで選ぶ操作（メニューバーは「ファイル」「表示」「ヘルプ」のメニューと、
      「検索と置換」のボタン）

- [ ] リンクの開き方の切り替え（Ctrl+クリック／クリックのみ。mdew は今はクリックのみで開く。mde の既定は Ctrl+クリック）

### Excel・PDF

- [ ] mdew から Excel へ貼り付けた時に、画像が文字や下の行に重なることがある（Excel は画像をセルの上に浮かせて置き、
      行を画像に合わせて高くしないため）。2026-10-14 に次の方法を試したが、期待した効果が無かったので元に戻した
  - 行の高さの指定（`<tr height=… style="height:…pt">`）：Excel 2010 では無視された
  - セルの中に空の改行（`<br style="mso-data-placement:same-cell">`）を入れて行を高くする：空白だけの行は消されて効かなかった
  - 段落の中の画像を画像だけの行に分けて、画像の高さの分の空の行を入れる・表の中の画像のある行を縦につなぐ（rowspan）：
    重なりは減ったが、表の行が不自然に高くなる等、見た目が期待どおりにならなかった
- [ ] PDF の中の相対パスのリンク（`other.md` 等）を開けるようにする（`file:///…` に書き換える。PDF ビューアーによっては
      確認が出る・開かないことがある）

- [x] **ヘルプメニュー・F1 で Readme を開く**（2026-10-14）
  - 「バージョン情報」のボタンを「ヘルプ」のメニュー（Alt+H）に変え、「Readmeを開く」（F1）と「バージョン情報」を置く（mde と同じ）
  - README.md はビルド時に実行フォルダへコピーし（csproj）、それを新しいウィンドウ（「新規」と同じく別のプロセス）で開く。
    msi もビルド出力の README.md を同梱する
  - F1 はメインのウィンドウでは画面側（main.js）、検索と置換・PDF の余白・バージョン情報のダイアログではホスト側

  - 同梱するファイル：mdew 本体、WebView2 SDK の DLL（Core・Wpf・WinForms）、WebView2Loader.dll（x64 用のみ。csproj の RuntimeIdentifier を win-x64 にして、実行フォルダの直下へ x64 用だけがコピーされるようにした）、
    `web\`（index.html・app.css・js\*.js）、README.md、LICENSE.txt、THIRD-PARTY-NOTICES.txt
  - ThirdPartyNotices.txt は実行フォルダへのコピーをやめ、`msi\THIRD-PARTY-NOTICES.txt` としてインストール先に同梱する

  - アイコン・アプリ名・作成者・著作権（csproj）、バージョン 0.0.1.0（ファイルバージョン・製品バージョンとも）、

- [x] **Markdown の文字を貼り付けた時に、書式（見出し・リスト等）に変換する**（2026-10-11）
  - `editor.js` の `pasteContent`・`pasteMarkdown`・`insertInlineMarkdown`
  - 書式なしで貼り付け：Ctrl+Shift+V、右クリックのメニュー
  - 引用の中に複数の段落を貼る場合、リストの項目の中にリスト以外の複数のブロックを貼る場合は、

- [x] **段落中の改行の表示の切り替え**（2026-10-12。メニュー「表示」の「段落中の改行」。
      既定は「空行が入るまで改行しない」。mde の既定は「ソースの通りに改行する」）
  - mde と同じく、切り替えた時は文書をいったん Markdown に書き出して読み直す（元に戻すの履歴は消える）。
    mde のサブメニューの代わりに、「表示」のメニューの中に見出しを付けて並べている
  - 「空行が入るまで改行しない」の時は、改行を `<br>` ではなく文字の改行（\n）のまま置き、ブラウザに空白として
    表示させる（`markdown.js` の `setJoinSoftBreaks`）。保存する時は改行のまま。ただし改行のすぐ隣で入力すると、
    ブラウザがその改行を空白に置き換えることがある（mde では、この表示で編集した段落の改行はすべて空白になる）
- [x] **フォルダビュー・すべて保存・検索と置換**（2026-10-12。mde から移植）
  - フォルダビューは、メニュー「ファイル」→「フォルダを開く...」で開いた時だけ表示する（mde はファイルを開いた時も、
    そのフォルダを表示する）。一覧の内容・並び順・「* 」・開き直しは mde と同じ（`folder.js`、Program.cs の ListMarkdownEntries）
  - フォルダを開いている間は、保存せずに別のファイルへ切り替えても変更を置いておき、開き直すと戻す（mde と同じ）。
    mde との違い：開き直した時に未保存の印を消さない（mde は消えて、そのまま切り替えると変更が失われる）。
    新規の文書（無題）から切り替える時は確認する（mde は確認なしで消える）
  - 検索と置換は、2026-10-13 に mde と同じ別のウィンドウ（`dialog\FindReplaceWindow`）に変えた（それまでは画面の右上に
    重ねるパネル）。処理は画面側（`find.js` の FindEngine）で行い、ウィンドウは入力と結果の表示だけを受け持つ。
    見た目・項目・メッセージは mde と同じ。
    mde との違い：画面の文字の検索で、書式の境目をまたいで見つける。1件ずつ置換（現在のファイル）でも $1 等が使える。
    正規表現の誤りはメッセージを出す。フォルダ全体の「次を検索」は今のファイルの中から始める
  - 検索条件は、ウィンドウを閉じるまで残る（mde と同じく、次回の起動には引き継がない）
- [x] **フォルダを指定しての起動**（2026-10-12）：フォルダビューに読み込んで、直下の最初のファイルを開く（mde と同じ。
      Program.cs の OpenStartupPath → OpenFolderPath）
- [x] **ソースモード**（2026-10-12。mde から移植。メニュー「表示」→「ソースモード」。終了時には覚えない）
  - 入力欄（textarea）で Markdown のソースを編集する。背景の色・余白は mde と同じ。切り替えた時のカーソル・表示の位置は、
    mde と同じく段落などのまとまり単位で合わせる。入力欄の内容を変えずに戻った時は読み直さない（元に戻すの履歴も残る）
  - mde との違い：ソースモードでも検索と置換が使える（mde は見つからない）。ソースモードのままファイルを切り替えても、
    変更は消えない（mde は消える）。アウトラインはソースの見出しの行から作る
  - 入力欄の後ろに同じ文字の配置の要素（#source-backdrop）を重ねて、検索の色と行の位置の計算に使っている
- [x] **検索のウィンドウ・範囲選択の色・画像を開く・Excel 連携・PDF・`<img>` の画像**（2026-10-13）
  - 検索と置換のウィンドウを、mde と同じくメインのウィンドウの外へ動かせる別のウィンドウにした（閉じても隠すだけ）
  - 範囲選択の色：Typora（#dae3e9）・サクラエディタ（#c1cfe3）に合わせ、淡い青（#c8d6e8。`app.css` の `--selection-bg`）
  - 画像のダブルクリック・右クリック「画像を開く」：ホストが参照先をファイルのパスにして既定のアプリで開く
    （Program.cs の OpenImage。画像の拡張子のファイルだけ開く）
  - Excel 連携（`clipboard.js`）：「Excel用にコピー」「表をコピー」は mde の ClipboardHtmlBuilder・TableEditor を移植。
    通常のコピーにも、罫線付きの HTML と mdew 用の Markdown（text/x-mdew-markdown）を付ける。
    mde との違い：通常のコピーでも他のアプリに書式付きで貼り付く（mde は WPF の標準のコピー）。
    表だけの HTML が1セルだけの場合と、行ごとのセルの数がそろっていないタブ区切りの文字は、表にしない
  - PDF：WebView2 の PrintToPdfAsync で直接 PDF を作る（mde は印刷のダイアログで Microsoft Print to PDF を選ぶ）。
    A4 縦、余白は mde と同じ設定（px）。ソースモードでも書き出せる（mde は Markdown モードだけ）
  - `<img ...>` の画像（mde と同じ）：src・alt・title・width・height と、style のうち大きさ・余白等だけを使う。
    保存する時は書いたままのタグにする。あわせて `C:\...` の絶対パスの画像も表示できるようにした
