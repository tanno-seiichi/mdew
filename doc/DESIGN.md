# mdew 設計メモ（開発者向け）

mde の画面を HTML で作り直したアプリケーションです。この文書は、mdew の作りと、できることの一覧を開発者向けに
まとめたものです（使い方は、リポジトリの直下の `README.md` を参照してください）。

## フォルダ構成

- `mdew.sln`：ソリューション（`mdew\mdew.csproj` と `msi\msi.wixproj` の2つのプロジェクト）
- `README.md`：ユーザーズガイド（初めて使う方向けの使い方）。インストーラーにも同梱します
- `LICENSE.txt`：mdew のライセンス（MIT）
- `doc\DESIGN.md`：この文書（開発者向けの設計メモ）
- `doc\TODO.md`：作業予定（mde にできて mdew でまだできないこと、確認が残っているもの、対応済みのこと）
- `mdew\`：アプリ本体のプロジェクト
  - `mdew.csproj` / `Program.cs` / `AppSettings.cs`：WebView2 を載せる入れ物（WPF）。
    ファイルを開く・保存する、画像の保存など、OS とのやり取りを担当します（ari 版と同じもの）。
    64bit（x64）専用です（`RuntimeIdentifier` を `win-x64` にしているので、WebView2Loader.dll は x64 用だけが
    実行フォルダの直下にコピーされます）。
  - `dialog\AboutWindow.xaml`：バージョン情報のウィンドウ（mde から移植）
  - `dialog\FindReplaceWindow.xaml`：検索と置換のウィンドウ（mde から移植。検索・置換の処理は `web\js\find.js`）
  - `dialog\PdfMarginDialog.xaml`：PDF の余白の設定（mde から移植）
  - `images\mde.ico` / `images\mde.png`：アプリのアイコン（mde と同じもの）
  - `web\`：画面側。ビルドは不要で、ここのファイルがそのまま実行フォルダへコピーされます。
  - `index.html` / `app.css`：画面の構成と見た目
  - `js\main.js`：画面全体の動き、ホスト（C#）とのやり取り
  - `js\editor.js`：編集部分（入力時の書式変換、元に戻す、編集していない部分を元のまま保存する仕組み）
  - `js\markdown.js`：Markdown の読み込み・書き出し
  - `js\folder.js`：フォルダビュー
  - `js\find.js`：検索と置換
  - `js\clipboard.js`：Excel 等の他のアプリとのコピー・貼り付け
- `msi\`：インストーラー（WiX Toolset 4）のプロジェクト（mde の msi を元にしたもの）
  - `Package.wxs`：製品名・バージョン・アップグレードコード・アイコン等
  - `Directory.wxs`：インストール先のフォルダ構成（`web\js` を含む）
  - `File.wxs`：同梱するファイルの一覧と、エクスプローラーの右クリックメニュー「mdew で開く」・スタートメニューへの登録。
    MSI はファイルを１つずつ列挙する必要があるため、`web\` にファイルを追加・削除した時や、
    NuGet のパッケージを追加・更新した時は、ここも直してください
  - `UpgradeConfirmDlg.wxs`：アップグレード時の確認・右クリックメニューを追加するかの確認の画面
  - `Package.ja-JP.wxl` / `Package.en-US.wxl`：画面の文言（日本語版・英語版の msi がそれぞれ作られます）
  - `License.rtf` / `LICENSE.txt`：インストール時に表示する・同梱するライセンス
  - `THIRD-PARTY-NOTICES.txt`：サードパーティ（WebView2 SDK）のライセンス表示。インストール先に同梱します。
    NuGet のパッケージを追加・更新した時は、この中のバージョン・ライセンス文も直してください

## ビルド

Visual Studio で `mdew.sln` を開いてビルドするだけです（Node.js は不要です）。

構成を Release にしてソリューションをビルドすると、インストーラーも作られます
（`msi\bin\x64\Release\ja-JP\mdew.msi` と `en-US\mdew.msi`）。インストーラーには mdew の実行フォルダ
（`mdew\bin\Release\net8.0-windows`）のファイルが入るので、先に mdew のビルドが通っている必要があります
（ソリューションのビルドでは、プロジェクトの参照により mdew が先にビルドされます）。

## 今できること（成立確認の範囲）

- 見出し・段落・箇条書き・番号付きリスト（入れ子）・チェックボックス・引用・コードブロック・水平線・表・画像・リンクの表示と編集
- 入力時の書式変換：行頭の `# ` `- ` `1. ` `> ` `[ ] `、`**太字**` `*斜体*` `~~取り消し線~~` `==ハイライト==` `` `コード` ``、
  「```」＋Enter でコードブロック、「---」＋Enter で水平線、「|見出し|見出し|」＋Enter で表
- リストの Tab / Shift+Tab、表のセル間の Tab 移動（最後のセルで Tab を押すと行を追加）
- 元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）
- 文字の書式：太字（Ctrl+B）・斜体（Ctrl+I）・下線（Ctrl+U）・取り消し線（Alt+Shift+5）・
  インラインコード（Ctrl+Shift+`）・ハイライト。右クリックのメニューからも使えます（表のセルの上では表の操作も）
- フォルダビュー（mde と同じ内容）：メニュー「ファイル」→「フォルダを開く...」で開いた時だけ、左端に表示します。
  - フォルダの中のサブフォルダと Markdown ファイル（.md・.markdown）の一覧。クリックでファイルを開きます
  - 保存していないファイルは名前の先頭に「* 」。別のファイルへ切り替えても変更は消えず、開き直すと戻ります。
    「ファイル」→「すべて保存」でまとめて保存します（閉じる時は、保存していない変更があれば確認します）
  - 上の「…」で別のフォルダを開き直せます。「表示」→「フォルダを表示」で隠せます
  - 起動時の引数にフォルダを指定した場合も、そのフォルダを開いて、直下の最初のファイルを開きます（mde と同じ）
- ソースモード（「表示」→「ソースモード」。mde と同じ）：Markdown のソースを直接編集します。
  切り替えた時は、カーソルと表示の位置を同じ段落などに合わせます。検索と置換・保存・ファイルの切り替えも使えます。
  終了時には覚えません（次回は Markdown モードで起動します）
- 検索と置換（Ctrl+F・メニューバーの「検索と置換」。mde と同じウィンドウで、メインのウィンドウの外へも動かせます）
  - 対象範囲：現在のファイル／フォルダ全体（サブフォルダ含む。フォルダを開いている時だけ）
  - 大文字・小文字を区別する、正規表現を使用する（置換後の文字列で $1 等が使えます）
  - 前を検索・次を検索・すべて検索（Enter）、置換後の文字列を開くと 1件ずつ置換…・すべて置換。Esc で閉じます
  - 結果の一覧はダブルクリックでその箇所へ移動します。閉じても入力した内容は残ります
  - フォルダ全体の置換は、保存するまでファイルには書き出しません（フォルダビューに「* 」が付きます）
- 「表示」のメニュー（Alt+V）：アウトラインを表示・ステータスバーを表示（表示中は ✓）、
  段落中の改行（ソースの通りに改行する／空行が入るまで改行しない。mde と同じ。既定は「空行が入るまで改行しない」）。
  次回起動時も同じ表示にします。
  「空行が入るまで改行しない」は表示だけの切り替えで、保存する内容は変わりません（改行のすぐ隣で文字を入力すると、
  その改行が空白に変わることがあります）
- 「ファイル」のメニュー（Alt+F）：新規（Ctrl+N）・開く（Ctrl+O）・保存（Ctrl+S）・名前を付けて保存（Ctrl+Shift+S）・
  閉じる（Ctrl+W。このウィンドウを閉じます）。新規は新しいウィンドウを開きます
- 最近使ったファイル（「ファイル」のメニューのサブメニュー。mde と同じ）：開いた・保存したファイルを、新しい順に 10 個までフルパスで表示します。
  クリックで開きます（見つからないファイルは、知らせて一覧から消します）。「履歴をクリア」で空にします。
  一覧は次回起動時も、ほかのウィンドウとも同じです
- 最近使ったフォルダ（「ファイル」のメニューのサブメニュー。「最近使ったファイル」の下）：「フォルダを開く...」・起動時の引数・
  この一覧で開いたフォルダを、新しい順に 10 個までフルパスで表示します。見つからないフォルダ・履歴をクリアは、最近使ったファイルと同じです
- PDF に書き出し（「ファイル」→「PDFに書き出し…」・Ctrl+P）：保存先を選ぶと、A4 縦の PDF に書き出して開きます。
  余白は「PDFの余白を設定…」で変えられます（px。既定は上下 64・左右 80。mde と同じ）。ソースモードでも書き出せます
- 範囲選択の色は、Typora・サクラエディタと同じく淡い青（文字の色はそのまま）
- 画像：ダブルクリック・右クリックの「画像を開く」で、既定のアプリで開きます（http(s) の画像はブラウザ）。
  `<img src="..." width="..." style="...">` の形で書いた画像も表示します（mde と同じ。保存する時は書いたまま）。
  `C:\dir\a.png` のような絶対パスの画像も表示します
- Excel・他のアプリとの連携（mde と同じ）
  - コピー（Ctrl+C）は、他のアプリに書式付きで貼り付きます（表は罫線付き）。mdew どうしでは見出し・表等の書式のまま貼り付きます
  - 右クリックの「Excel用にコピー」：見出し・段落・項目等を、Excel で1行1セルに分かれて見た目も保つ形でコピーします。
    表の中では選んだセルの範囲をコピーします
  - 右クリックの「表をコピー」（表のセルの上）：表全体を罫線付きでコピーします
  - Excel の範囲（タブ区切りの文字）を貼り付けると、表になります（1つ目の行が見出しの行）
- 開いているファイルの名前は、タイトルバーに表示します
- ステータスバーの「停止」「入力遅延」の回数（IME フリーズの検証用）は、Debug ビルドの時だけ表示します
- 文字の貼り付けは、Markdown として読んで書式（見出し・リスト・表・太字等）にします。
  書式にしたくない時は「書式なしで貼り付け」（Ctrl+Shift+V・右クリックのメニュー）
- 「ヘルプ」→「Readmeを開く」（F1）で、実行フォルダの README.md を新しいウィンドウで開きます（mde と同じ。
  README.md はビルド時に実行フォルダへコピーされます。検索と置換等のダイアログでの F1 は、ホスト側の Program.Main で受けます）
- 「ヘルプ」→「バージョン情報」で、アプリ名・バージョン・著作権を表示します（mde の AboutWindow と同じ画面）
- F12 で開発者ツール（画面側の調査・デバッグ用）を開きます
- リンクはクリックで開きます（`#見出し` は文書内の見出しへ移動、http(s)・mailto は既定のアプリ、相対パスの .md はこのウィンドウ）。
  リンクの文字を編集する時は、矢印キーでカーソルを移動します
- 編集していない部分を元のまま保存、クリップボードの画像の貼り付け

## フォント・文字の大きさの変更

`web\app.css` の先頭の `:root { … }` にまとめてあります（`--doc-font`・`--doc-font-size` 等）。
書き換えてビルドし直すと反映されます。
